## 隆老師的提示語

> 我要依照已確認的「光影奇航」講義製作課堂用 HTML 簡報，最後以單一 index.html 交付，CSS 與 JavaScript 都內嵌在檔案中。請先規劃投影片地圖，不要寫程式。內容需要依序帶學生看見作品、提出驅動問題、理解距離／角度／旋轉造成的影子變化、接收設計任務與安全提醒，最後回到學習單的反思。請依教學需要決定頁數；每頁只處理一個主要訊息，並列出該頁目的、畫面文字、教師或學生動作，以及需要的視覺素材。互動以瀏覽器原生功能可完成為原則，不要新增講義以外的事實。
