> 請依照剛才確認的投影片規劃，製作一份可以直接在瀏覽器開啟的簡報。請只輸出一個完整的 index.html，把 CSS 寫在 style 標籤、JavaScript 寫在 script 標籤中，不使用框架、套件或建置工具。使用繁體中文，每頁聚焦一個重點；加入上一頁、下一頁、頁碼、鍵盤方向鍵、全螢幕、進度提示與基礎轉場動畫，並讓手機畫面正常閱讀。若使用圖片，請以 images 資料夾中的相對路徑引用。
