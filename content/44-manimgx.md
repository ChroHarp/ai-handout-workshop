## 我如何交辦給 Agent

- **交代教學需求**：我提供數學概念、講解順序與想呈現的畫面，請 Agent 操作 ManimGX 製作動畫。
- **確認分鏡**：Agent 自動拆分場景，安排每幕出現的公式、圖形和動畫。我確認講解順序後，再進入製作。

<!-- column -->

## Agent 如何操作工具

- 依分鏡編排動畫、合成旁白語音、產生對時字幕，再渲染成影片。
- 我看預覽、指出要修改的片段，Agent 調整後重新渲染。
